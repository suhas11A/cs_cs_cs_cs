# Week 3
Asm Lab Week 3 consists of 3 tasks
## Task 1
- Learn how structs can be used in assembly
- Understand the memory layout of structs and how to access fields of a struct
- Understand the implementation of print_float 
- Implement print_complex which takes in the address of a complex struct, a message string and prints its values in the format given in the PS (format string given in the template)
- Compile using `bash compile.sh` from within the `task1` directory and run using `./print_cmplx`
## Task 2
- Understand addition of complex numbers
- Finish up the template for add_cmplx which takes in the address of two complex numbers, reads their fields and adds them 
- Compile using `bash compile.sh` from task2 directory and run using ./basic_cmplx_arith.asm
# Task 3
- Understand reciprocal of complex numbers
- Finish up the template for recip_cmplx which takes in the address of a complex number, reads its  fields and creates its reciprocal 
- Compile using `bash compile.sh` from task2 directory and run using ./adv_cmpl_arithm.asm
