# isHeap

## Objective
Implement a function to check whether a given array represents a **max-heap**
---

## Problem statement
Given an integer `n` and an vector `data` of `n` integers representing the level-order (breadth-first) traversal of a binary tree using **0-based indexing**, determine whether `data` satisfies the **max-heap property**:

### Input format
- First line: integer `n` (number of elements)
- Second line (optional when `n == 0`): `n` integers (space-separated) — the array

### Output format
- Print `YES` if the array is a max-heap, otherwise print `NO`.


### Your Task
In **isHeap.cpp** complete isMaxHeap() function
Do **not** modify any other files.
